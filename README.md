# Naruka AI Labs

Building AI-powered educational, productivity, and intelligent assistant solutions.

## About

Naruka AI Labs is an early-stage AI startup focused on developing intelligent software solutions that improve learning, productivity, and accessibility.

Our mission is to build practical AI-powered applications using:

* Large Language Models (LLMs)
* AI Agents
* Retrieval-Augmented Generation (RAG)
* Cloud Computing (AWS)
* Full Stack Development
* IoT Integration

## Current Projects

### AI Learning Assistant

An AI-powered platform that helps students learn faster through personalized explanations, quizzes, and study plans.

### Smart AI Glasses (Research Project)

An intelligent wearable device capable of real-time object recognition, voice interaction, and contextual assistance.
